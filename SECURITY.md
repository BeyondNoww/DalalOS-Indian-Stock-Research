# Security

Please report suspected security issues privately.

## Reporting a vulnerability

Email: `hello@dalalos.in`

Include enough information to reproduce and understand the issue, but **do not** include real API keys, access tokens, passwords, private customer data, or other live credentials unless a secure exchange method has been explicitly arranged.

Please do not open a public GitHub issue containing:

- credentials or authentication tokens;
- exploitable vulnerability details before coordinated review;
- private user/account data;
- internal service or infrastructure information obtained through unintended access.

This repository contains only public integration/discovery material. The production DalalOS service is hosted separately at `dalalos.in` / `mcp.dalalos.in`; absence of implementation code here does not mean a reported issue is out of scope.

For general product questions that are not security-sensitive, use `hello@dalalos.in` or the documentation at https://dalalos.in/docs.
